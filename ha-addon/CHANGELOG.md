# Changelog

## [2.0.0] - 2026-08-22
### Added
- Multi-architecture native support for `aarch64` (ARM64), `amd64` (x86_64), `armhf`, `armv7`, and `i386`.
- Full Home Assistant Ingress integration with reactive dashboard styling.
- Real-time job control engine with pause, resume, retry, and cancellation capabilities.
- Live progress feedback with dynamic bitrate extraction and M3U auto-sync.
- Comprehensive UI Configuration Schema and translation mappings for pre-installation setup.
- High-resolution SVG and PNG branding assets.
